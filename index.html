EY · DigiGST 2.0 · Azure

A GST messaging platform tuned to 21× its expected peak

EY's GST compliance platform has to survive filing-deadline bursts. I designed the Apache Pulsar platform on AKS and tuned it through EY's performance testing.

  • Deployed Pulsar with Helm: ZooKeeper StatefulSets, cert-manager TLS, JWT auth and automated sinks.
  • Right-sized CPU and memory requests so autoscaled pods actually took traffic.
  • Traced node CPU saturation in Grafana to Pulsar and the app sharing one node pool.
  • Proposed dedicated AKS node pools as the path to 5,000 TPS.

AgentCORE: an MLOps platform for AI agents

CoreOps.ai needed one place to build, train, deploy and monitor AI agents. I designed, built and launched it as the sole DevOps engineer.

  • Separate staging, UAT and production environments with promotion between them.
  • Jenkins CI/CD with SonarQube quality gates on every change.
  • Prometheus and Grafana monitoring for models, services and infrastructure.
  • Rightsized the production VM as part of company-wide cost governance.
